# From a draft to a usable request / 从草稿到可复用的提问

The personal workspace draft was selected by the author for demonstration; the other three drafts are fictional. English originals translate the Chinese drafts. All rewrites are curated examples, not model-run evidence or promises of repeatability.

个人工作台原话由用户指定用于展示，其余三组为虚构通用需求。英文原话为中文的对应翻译。完善稿均为编辑示例，不是模型实测记录，也不保证每次获得完全相同的措辞。


## 1. 说清设计感觉 / Describe the design

**你的草稿**

我想要设计一个个人工作台，希望他高端、大气、上档次，页面排版也好看。

**可复用的提问**

请为我设计一个个人工作台，整体呈现高端、大气、有质感的视觉效果。页面布局应主次分明、比例协调，注重留白、对齐、间距和字体层次；配色与组件风格保持统一，让界面美观、清晰、易于阅读和使用。若用途、核心功能或使用平台尚不明确，请先简短确认，再展开设计。

把审美感受转为可执行的视觉要求；功能和平台仍由用户决定。

**Your draft**

I want to design a personal workspace. I want it to look high-end, impressive and refined, with an attractive page layout.

**Ready to reuse**

Design a personal workspace with a high-end, impressive and refined visual style. Use a clear hierarchy and balanced proportions, with thoughtful whitespace, alignment, spacing and typography. Keep colors and components consistent so the interface is attractive, clear and easy to read and use. If its purpose, core features or target platform are unclear, briefly clarify them before developing the design.

Translate an aesthetic preference into visual criteria; leave features and platform to the author.


## 2. 说清沟通目的 / State the purpose

**你的草稿**

帮我写封邮件，跟对方说周三之前给我确认一下交付时间，语气礼貌但别太绕，别替我承诺新的日期。

**可复用的提问**

请起草一封邮件，请对方在周三之前确认交付时间。措辞礼貌、直接，避免冗长铺垫；不要代我承诺新的交付日期。

保留确认期限与语气要求，不把“催确认”变成“重新承诺”。

**Your draft**

Write an email asking them to confirm the delivery timing by Wednesday. Be polite but get to the point, and do not promise a new date for me.

**Ready to reuse**

Draft a polite, direct email asking the recipient to confirm the delivery timing by Wednesday. Avoid a lengthy introduction and do not commit me to a new delivery date.

Keep the confirmation deadline and tone without turning a follow-up into a new commitment.


## 3. 说清整理边界 / Define the boundaries

**你的草稿**

把我贴的反馈分成问题和建议，算下每类有几条，别补我没给的评论，不好归类的单独放。

**可复用的提问**

请仅根据我提供的反馈，将内容归为“问题”和“建议”，并统计每类条数。无法明确归类的反馈单独列出，不补充未提供的评论。若尚未提供反馈原文，请先向我索取。

明确可使用的材料与分类边界，资料缺失时只要求补充。

**Your draft**

Sort the feedback I paste into problems and suggestions and count each category. Do not add comments I did not provide. Put anything hard to classify separately.

**Ready to reuse**

Using only the feedback I provide, group entries into problems and suggestions and count each category. List entries that cannot be clearly classified separately; do not add comments absent from the source. If the feedback has not been supplied, ask me for it first.

Specify the source and category boundaries; request missing input without creating it.


## 4. 说清解释范围 / Keep the scope exact

**你的草稿**

帮我解释这段配置，重点说 retry_limit=3 和 timeout_ms=5000 的含义，只解释不要改，字段和值都别动。

**可复用的提问**

请解释我提供的配置，重点说明 retry_limit=3 和 timeout_ms=5000 的含义。仅作解释，不修改配置，准确保留字段名称与数值。若未提供配置内容，请先向我索取。

保留字段、数值和“只解释”的边界，不替用户修改配置。

**Your draft**

Explain this configuration, especially retry_limit=3 and timeout_ms=5000. Explain only; do not edit it or change any fields or values.

**Ready to reuse**

Explain the configuration I provide, focusing on retry_limit=3 and timeout_ms=5000. Provide an explanation only; do not modify the configuration, and preserve field names and values exactly. If the configuration is missing, ask me to supply it.

Keep exact fields, values and the explanation-only scope; do not modify the configuration.
