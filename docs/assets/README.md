# About the demonstration assets / 展示素材说明

The main example starts with the personal workspace draft selected by the user. The other three examples use fictional, general-purpose requests. English originals translate the Chinese drafts. All before/after examples are curated copy; actual model checks are recorded separately and are not represented by these images.

The Windows images render the production WPF components with demonstration text. The surrounding composer is a layout illustration, not a user's chat screenshot. English assets render the translated controls themselves. Skill assets typeset the draft beside the revised request. Local HTML/CSS and code produce these materials; no third-party artwork or font files are redistributed.

主案例采用用户指定的个人工作台原话，其余三组为虚构通用需求；英文原话由中文对应翻译。完善稿是编辑示例，模型实测输出另有记录，图片不构成效果保证。

工具图片来自真实 WPF 组件的受控渲染，输入框背景是布局示意；英文素材直接渲染英文组件。Skill 图片以左右对照展示改写前后。材料不含私人聊天截图、项目图片、凭据或原始参考文件。

- `hero-en.png` / `hero-zh.png`: README demonstrations / 说明页展示图。
- `social-en.png` / `social-zh.png`: 1280 × 640 social-preview images / 仓库预览图。
- Other images are named for the example or component state / 其余图片按案例或界面状态命名。

These demonstration assets are included under the repository's MIT license. / 这些展示素材随仓库采用 MIT 许可证。
